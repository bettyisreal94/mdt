This repository contains a Rust project for a command line application that
deals with extended Markdown tables as defined on
`./tmp/extended-markdown-table/README.md`.

The current task is to improve the output generated by the `dump` function
on `src/parser.rs`. The output string is not properly formatted. All columns
should be as big as the largest value inside it while also including some
padding. So a table such as

```
| name | age |
|---|---|
| mira | 21 |
| sprocket | 10 |
| pietro | 1 |
```

Should actually look like this:

```
| name     | age |
|----------|-----|
| mira     | 21  |
| sprocket | 10  |
| pietro   | 1   |
```

Update the function to correctly output the formatted data. Update any
automated tests related to `dump` to ensure that the feature is implemented
correctly. Ask questions if you need clarifications.
